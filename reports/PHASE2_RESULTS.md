# Phase 2 交付与实验结果

日期：2026-10-29。交付范围：可运行的有界抽取—验证交互、真实生成判决 token 的 log-probability / 熵，以及运行记录与审计。代码和协议见 [Phase 2 方法说明](../docs/PHASE2.md)。模型为 Qwen2.5-3B-Instruct 固定 revision `aa8e72537993ba99e69dfaafa59ed015b17504d1`、FP16、greedy；抽取与验证使用同一模型的不同提示角色，不使用外部检索证据。

## 开发集：三个维度分别检查

对 10 条合成开发样本的最终一轮进行 agent 初审。预期事实和限定同样由 agent 设计并自审，不是独立人工金标准，数据被用于调整提示，以下不是独立评测成绩：

| 分项 | 观察 |
| --- | --- |
| 事实核心 | 17/17 个预期事实核心在原始候选中被提及；其中仍有依赖上下文或不符合原文逐字引用的情况。核心被提及不能证明主张独立或完整。 |
| 限定条件 | 22/22 项出现在所属原始候选；其中 20/22 项出现在被接受的引用里。 |
| 字符位置 | 最终 17 条候选中接受 14 条，14/14 与 `source[start_idx:end_idx]` 完全一致；拒绝 3 条，其中 2 条不是逐字原文、1 条因重复位置不唯一。 |

[逐句语义初审](phase2_dev_v6_semantic_review.json)和[分项计数](phase2_dev_v6_metrics.json)保留每条依据。开发冲突句中，逻辑检查明确指出同一房间同一时间恰好 5 与 7 把椅子不能并存，反馈进入第二轮；第二轮抽取没有变化。两个无矛盾对照只输出 `NO_CONTRADICTION`，未提供双方比较理由。句末带点的无矛盾标记已修复：开发句 D10 不再被误作反馈；其第二个事实虽在原始候选出现，仍因补写主语被拒绝为非字面引用。

早期开发试验记录和代码快照保存在 [phase2_development](phase2_development/)：v2 对冲突只有笼统提示；v3 和 v4 漏检该冲突；v5 在 D10 因 `NO_CONTRADICTION.` 误触发第二轮。v5 正式输入预运行了前 3 条后中止，问题来自开发集复核而非根据这些正式结果调参。v6 的代码、数据、模型配置和轮次在重启正式运行之前记录于 [冻结协议](phase2_frozen_protocol.json)。冻结时间由本机报告，并非独立可信时间戳。

## 正式输入：实际运行行为

60/60 条正式输入均已处理。第一轮有 84 条唯一可定位的原文引用，另有 22 条拒绝记录：19 条无法逐字匹配、3 条为空或无效数组。10 条输入将反馈传入第二轮，第二轮产生 17 条可定位引用和 2 条拒绝记录。两轮合计的 101 条引用是**出现次数**，包括同一引用跨轮重复，不是 101 个独立事实。

| 第一轮判决输出 | 数量 |
| --- | ---: |
| SUPPORTED | 61 |
| REFUTED | 4 |
| NOT_ENOUGH_INFO | 19 |

这些只是对第一轮 84 条被接受引用的闭卷模型输出分布，不是真假准确率；原始 60 条的整句 `Refuted` 标签不能自动赋给上述引用。共 10 次反馈真正进入下一轮；源内逻辑角色两轮合计有 2 次非空意见，不能等同于检出两个真实错误。全部 342 次生成均记录 EOS，101 条判决的实际生成轨迹均有标签 token 对齐。结束原因：43 条无可执行反馈、9 条无有效引用、7 条重复抽取、1 条达到轮次上限；这些停止原因不保证逻辑核查成功。

第一轮实际生成的 212 个判决标签 token 的平均原始 log-probability 为 **-0.049106**，对应位置的平均全词表熵为 **0.112351 nats**。第二轮为 48 个标签 token，分别为 **-0.063690** 和 **0.117805 nats**。按 token 加权；这些不是校准真值概率，也不是两个候选类别间的后验概率。[逐轮汇总](phase2_formal_v6_summary_20261029.json)和[完整逐次轨迹](phase2_formal_v6_20261029.json)含每条原始输出和分数。

[正式输入前 10 条试阅](phase2_formal_first10_review.json)单独检查事实、限定与位置，非随机、非独立人工金标准，不能外推：发现复合事实未拆开、共享谓语缺失、时间/背景遗漏；一条样本的第二轮输出空数组，丢失第一轮候选。这表明反馈不一定改进结果。前 10 条最终接受 11 条引用，均精确匹配切片；另有两条拒绝记录（非字面引用及空数组）。

## 运行检查

- `python scripts/validate_phase2_dev.py`：10 条开发样本、17 个预期事实、18 个事实引用位置、22 项限定及 3 对逻辑关系通过结构和字符位置检查；这不是语义正确性检查。
- `python scripts/audit_phase2_run.py --run runs/phase2_formal_v6_20261029.json --input data/phase1/inputs.json --output runs/phase2_formal_v6_audit_20261029.json`：60 条处理记录、70 轮、10 次反馈过渡及 101 条判决轨迹通过内部一致性审计；见[审计结果](phase2_formal_v6_audit_20261029.json)。
- `python scripts/audit_phase2_freeze.py ...`：模型配置、源码和数据哈希一致，记录的冻结时间早于正式运行，正式输入前缀及完整数量匹配；见[冻结审计](phase2_formal_v6_freeze_audit_20261029.json)。
- 使用同一模型对第一条真实判决的完整 prompt 与生成 token 做 teacher-forced 前向复算，包括 EOS；与生成时保存值的最大绝对差为 log-probability **0.000438**、全词表熵 **0.001492 nats**。这是单条轨迹、两种前向执行路径的实测差异，不代表所有轨迹逐位相同；见[复算记录](phase2_formal_v6_logits_recheck_20261029.json)。
- `python -X utf8 -m unittest discover -s tests -q`：运行 99 项，98 通过、1 项因未提供本地 tokenizer 路径而跳过；对应真实 Qwen tokenizer 测试在本地模型环境另行运行通过。`python -X utf8 scripts/validate_phase1.py`、`python -X utf8 scripts/build_testset.py --check` 和 `git diff --check` 均通过。

Phase 2 已交付可执行的有界交互及实际生成 token 不确定度记录，**不代表模型已可靠识别事实错误**。后续 Phase 3 需要独立人工核验原子事实、限定和真伪，加入受支持对照，明确证据检索协议，并在预先冻结的评估中报告分母、误报与漏报。公开基准可能已被模型见过，不能以此证明真实新闻泛化能力。
