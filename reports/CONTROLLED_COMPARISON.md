# 本地与 Colab 受控比较

核验日期：2026-10-20（UTC+8）。两端各运行一次统一的 15 句测试；旧版三句结果未混入本次比较。

## 控制条件

- 同一份改进代码、提示词、15 句数据和预定义标注；四个受控文件 SHA256 及完整协议哈希相同。
- 模型 `Qwen/Qwen2.5-3B-Instruct`，revision `aa8e72537993ba99e69dfaafa59ed015b17504d1`。
- FP16、eager attention、seed=42、greedy、单 beam、最多 256 个新 token、repetition penalty=1；采样关闭。
- PyTorch `2.10.0+cu128`、Transformers `4.57.6`、Accelerate `1.15.0`、Tokenizers `0.22.2`、Safetensors `0.8.0` 相同。
- 每句实际提示词 token 哈希、实际加载精度／revision、生成默认值均一致。生成调用中的显式参数覆盖模型默认配置；包中保存的 `do_sample=true` 等模型默认值不是本次调用的有效参数。
- 两端 device map 相同：第 0–28 层在 GPU，第 29–35 层及部分末端模块在 CPU；GPU 权重预算 5 GiB。
- 协议哈希：`e8724c06a5ee7e99da5e8ca99468c59229794ba331ca45cb1990aab64f73fb0c`。

## 复现出的错误

- `repeat_01`、`repeat_02`：引用在原文中出现两次。模型提到了对应事实与限定，但程序拒绝猜测位置。
- `shared_01`、`shared_02`：模型在第二条引用中补写 `Meadow Clinic`／`Eastport Council`。命题核心及限定仍在，但引用不是原文连续子串，定位被拒绝。
- `time_01`：`From March 3 to March 8` 被改成 `From March 3 to March 3`。事件核心仍在，一项时间限定错误；该引用同时因非原文改写被拒绝定位。

这些是两端共同复现的提示词／抽取限制。本轮没有证据说明其中一个环境的抽取质量更好；也不将重复引文的安全拒绝当作模型漏提。

## 核验与复现

附件中的指标已在本地独立重算，并与收到的指标 JSON 完全一致；两端共 30 条生成记录均已重算定位、逐 token 均值与 token 数，并确认正常 EOS 结束。

```powershell
python compare.py reports/local_fp16.json reports/colab_fp16.json --output reports/controlled_comparison.json
python evaluate.py reports/colab_fp16.json --output reports/colab_metrics.json
python -m unittest discover -s tests -v
```

结果文件：`controlled_comparison.json` 为完整对照，`colab_fp16.json` 为 Colab 原始记录，`colab_metrics.json` 为独立重算指标，`colab_semantic_review.json` 为逐句复核，`comparison_integrity.json` 为完整性核验。

本轮只覆盖 15 个合成样本，每个环境一次正式运行；没有外部事实核查，也不据此推断真实新闻、其他模型或其他生成策略上的泛化表现。
